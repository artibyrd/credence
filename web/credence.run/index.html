The 4 Pillars of Credence

1. Rigorous Multi-Agent Pipeline

4 specialist evaluation agents analyze rendered DOM trees, clean prose, and visual layouts against namespaced taxonomies (SPJ Code of Ethics, IEP Fallacies, and Deceptive UI Patterns).

2. Zero-Hallucination Grounded Citations

Every finding requires an exact verbatim DOM quote verified against the extracted DOM text. Fictitious or hallucinated citations immediately collapse the node's quality score.

3. 13-Node P2P Gossip Mesh Network

Nodes gossip signed attestations across a Watts-Strogatz small-world lattice with Bayesian consensus, Byzantine cartel resilience ($N \ge 3f + 1, f = 4$), and storm suppression.

4. FastMCP 2.0 & Claude Desktop Ready

Seamlessly expose live epistemic evaluation tools, dynamic resources, and prompt templates to AI agents via Server-Sent Events (SSE) and Stdio transports.

5. Empirical Subject Expertise (No Diplomas)

Domain authority ($E_i$) is mathematically earned purely through historical concordance and grounded citations—never through vulnerable static certificates.

6. Feed Ingestion & Generous Defaults

Automated RSS/Atom/JSON feed pre-ingestion with BitTorrent-inspired work sharing: 1 node audits an article, and all mesh peers adopt it at $0.00 token cost.
