How It Works

From Raw Article to Verifiable Receipt

A simple, transparent 4-step pipeline designed for speed and accuracy.

1

1. Clean Content Capture

Headless Chromium captures the rendered page, strips away ads and tracker noise, and extracts clean prose while preserving the original layout and structure.

2

2. Multi-Rule Ethical Audit

Evaluates content against clear, standardized catalogs: journalistic ethics (unnamed sources, unverified allegations), logical fallacies, and deceptive user interface patterns.

3

3. Verbatim Quote Validation

Every identified issue is strictly cross-referenced against the raw text. If the evidence cannot be highlighted word-for-word in the original article, it is discarded.

4

4. Cryptographic Proof Receipt

The audit report is signed with an Ed25519 cryptographic signature. Anyone can verify the results and share them across the peer network at zero cost.
