# Introducing Credence v1.0.0: Practical, Verifiable Web Ingestion and Collaborative Fact-Checking for Developers and AI Agents

Today, we are announcing the open-source **v1.0.0 release of Credence**—an autonomous epistemic evaluation engine, FastMCP 2.0 server, and decentralized trust network built to verify online claims and protect AI agents from deceptive web content.

---

## The Problem: Web Ingestion is Broken for Autonomous Agents

As developers build autonomous AI agents (in Cursor, Claude Desktop, LangChain, or custom agentic loops), agents are routinely instructed to browse the live web, fetch articles, and make technical or business decisions based on what they read.

However, the modern web is filled with:
1. **Sensationalized Anonymous Clickbait**: Viral articles asserting extraordinary claims with zero named sources or verifiable attribution.
2. **Cloaked Disinformation**: Deceptive content claiming to be "satire" to evade liability while advancing harmful medical, financial, or civic claims.
3. **High Token Compute Costs**: Running repeated multi-agent LLM fact-checking pipelines across high-volume syndicated RSS feeds is financially prohibitive ($1,000s/month in token bills).

**Credence solves these challenges through transparent, grounded evaluation rules, cryptographic attestation, and cooperative P2P work-sharing.**

---

## Key Features in Credence v1.0.0

### 1. Grounded Journalistic Auditing in One Command
Evaluate any web page against standardized, machine-readable ethical rules (including the Society of Professional Journalists Code of Ethics, Logical Fallacies, and Rhetorical Deception catalogs):

```bash
credence audit https://example.com/breaking-news
```

Credence parses the live DOM, validates citations against exact character substrings in the text ($G = 1.0$), calculates suspicion scores and violation densities, and generates an immutable cryptographic report.

### 2. FastMCP 2.0 for Claude Desktop & Cursor
Give your AI coding assistant and research agents an epistemic brake. Credence exposes high-performance MCP tools (`credence_check_url`, `credence_evaluate_text`) over standard I/O and SSE transports.

Simply add Credence to your `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "credence": {
      "command": "credence",
      "args": ["serve", "--transport", "stdio"]
    }
  }
}
```

When your agent browses a URL, it queries Credence to confirm claim grounding before ingesting the text into its context window. All untrusted external text is strictly containerized inside `<untrusted_source_text>` blocks to neutralize prompt injection attacks.

### 3. BitTorrent-Style Cooperative Feed Ingestion (92.3% Compute Savings)
Instead of every developer burning tokens to evaluate the same syndicated news feeds, Credence nodes can join a decentralized P2P mesh cluster. 

Nodes divide RSS/Atom feeds across peers, sign audit reports with local Ed25519 keys, and gossip attestations over WebSocket relays. Peers verify incoming signatures and adopt cached evaluations at **$0.00 token cost**, achieving **92.3% compute savings**.

### 4. Zero-Key Developer Safety & Offline Heuristics
No API keys? No problem. When running in zero-configuration environments, Credence automatically falls back to an offline structural heuristic engine (`evaluation_method: "offline_structural_heuristic"`), ensuring developer CLI commands, tests, and CI/CD pipelines never crash or fail due to token budget exhaustion.

### 5. Universal 4-Layer Feature Parity
Credence maintains complete feature parity across all interfaces:
- **CLI**: Rich, colored terminal command suite (`credence audit`, `credence mesh`, `credence feeds`, `credence identity`).
- **FastMCP 2.0**: JSON-RPC 2.0 server for AI agent integrations.
- **Textual TUI**: Interactive terminal dashboard (`credence tui`) with real-time audit inspectors, key management, and P2P cluster monitoring.
- **Zero-Build Web Viewer**: Lightweight static HTML5/ES Module viewer with browser-native Web Cryptography signature validation (`window.crypto.subtle`) and zero npm dependencies.

## 60-Second Quickstart

Install Credence via POSIX one-liner or Python pip:

```bash
# Option A: One-line install
curl -sSL https://credence.run/install.sh | bash

# Option B: Install via pip / poetry
pip install credence

# Run your first audit
credence audit https://example.com/article
```
